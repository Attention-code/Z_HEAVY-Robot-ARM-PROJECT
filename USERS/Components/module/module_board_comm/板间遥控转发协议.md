# 板间遥控转发协议（Robot Link / module_board_comm）

## 概述

- 物理层：**FDCAN3，Classic CAN 1Mbps**（本板 `Core/Src/fdcan.c` 已按 Classic 配置）。
- 协议层：复用 ECF 开源组件 **`module_board_comm`**（Robot Link 协议），位于
  `USERS/Components/module/module_board_comm/`。**底盘板直接复用同一组件**，
  不需要手工拼帧。
- 数据流：i6x 接收机接底盘板 → 底盘板调 `module_board_comm_send_remote()` →
  本板 FDCAN3 中断收帧 → `module_board_comm_handle_frame()` 分片组装 →
  控制任务 1kHz 读取。方向暂为**单向**（底盘板 → 机械臂板，只传遥控）。
- 本地扩展：组件在 ECF 原版基础上**新增第 4 分片（扩展拨杆帧）**，
  用于承载 i6x 比协议原生开关位多出的 SWC/SWD。

## CAN ID 分配

| 方向 | 基址 | 帧序列 | 内容 |
|------|------|--------|------|
| 底盘板 → 机械臂板 | **0x710**（底盘板发送基址 = 本板接收基址） | 0x710 / 0x711 / 0x712 / 0x713 | 遥控四帧分片 |
| 机械臂板 → 底盘板 | **0x720**（预留） | 0x720~0x727 | 机械臂状态回传（暂未实现） |

底盘板初始化时配置：

```c
module_board_comm_config_t cfg = {
    .can = <底盘板 FDCAN3 的 bsp_can_t*>,
    .transmit_base_identifier = 0x710U,   /* 必须等于机械臂板的接收基址 */
    .receive_base_identifier  = 0x720U,   /* 预留：接收机械臂板回传 */
    .transmit_timeout_ms      = 2U,
    .offline_timeout_ms       = 100U,
};
module_board_comm_init(&comm, &cfg);
```

## 发送侧（底盘板）

周期任务（建议 10~50ms 一次）把 i6x 数据映射到
`module_board_comm_remote_process_data_t` 后调用：

```c
module_board_comm_send_remote(&comm, &remote_data);
```

内部自动发 **4 帧、共用同一递增序列号**（接收端按序列号 + 掩码组装）：

| 帧 | ID | 载荷（字节 2~7） | 说明 |
|----|----|------------------|------|
| 1 | 0x710 | ch0 / ch1 / ch2（各 int16 小端） | 主通道 |
| 2 | 0x711 | ch3 / 拨轮 dial / keyboard（各 int16） | 辅助通道 |
| 3 | 0x712 | mouse_x / mouse_y / mouse_z（各 int16） | 输入事件 |
| 4 | 0x713 | switch_raw[0..3]（各 int8，原始档位）/ 预留 2B | 原始开关 |

帧公共格式：`[0]=序列号, [1]=flags, [2..7]=6 字节载荷`（共 8 字节）。

第三帧 flags 位定义（第三帧 payload 为鼠标）：

| 位 | 含义 |
|----|------|
| bit0~1 | 左拨杆（0=INVALID, 1=UP, 2=DOWN, 3=MIDDLE） |
| bit2~3 | 右拨杆（同上） |
| bit4 | 鼠标左键 |
| bit5 | 鼠标右键 |
| bit7 | 遥控器在线（is_online） |

第四帧载荷定义：`switch_raw[0..3]` 各占 int8，**i6x 原始档位直传**（+1=上 0=中 -1=下，
不映射成枚举），字节 4~5 预留为 0。第三帧 flags 的左/右拨杆位由底盘板置 INVALID=0，
应用侧开关统一从第 4 帧原始档位映射。

## 接收侧（机械臂板，已实现）

- FDCAN3 全收过滤器 → 中断回调 `robot_board_comm_frame_handler()`
  （见 `robot_config.c`）→ `module_board_comm_handle_frame()`。
- 时间所有者：控制任务每周期调用 `module_board_comm_update_time()`（1kHz），
  超过 `ROBOT_BOARD_COMM_OFFLINE_TIMEOUT_MS`（100ms）未收到完整四帧，
  `module_board_comm_get_remote()` 返回 NULL → 遥控判离线 → 安全监控断使能。
- 读取：`robot_adapter_remote_update()`（见 `robot_adapter.c`）把
  `channel[0..3]`、SWA/SWB（left/right_switch）、SWC/SWD（ext_switch）映射到
  `app_remote_input_t`；开关枚举两侧行值一致（0/1/2/3），直接强转。
- 调试日志：控制任务每 100ms 经 RTT 打印全 8 通道（`ROBOT_REMOTE_DEBUG_LOG`）。

## i6x → 协议字段映射约定（底盘板实现时必须遵循）

i6x 全 8 通道：CH1~CH4 摇杆（±660）+ CH5~CH8 拨杆 SWA/SWB/SWC/SWD
（SWA/SWB/SWD 两档：上/下；SWC 三档：上/中/下）。
**开关档位全程直传 i6x 原始值（+1=上 0=中 -1=下），两侧都不做枚举转换。**

| i6x 字段 | 协议字段 | 说明 |
|----------|----------|------|
| `ch[0]`~`ch[3]`（CH1~CH4 摇杆） | `channel[0]`~`[3]` | ±660 原值透传，接收端做死区/归一化 |
| `s[0]` SWA | `switch_raw[0]` | 原始档位直传（+1/-1） |
| `s[1]` SWB | `switch_raw[1]` | 同上 |
| `s[2]` SWC（三档） | `switch_raw[2]` | 原始档位直传（+1/0/-1） |
| `s[3]` SWD | `switch_raw[3]` | 同 SWA |
| 失控/超时 | `is_online` | 第三帧 flags bit7 |
| — | `left_switch`/`right_switch`（第3帧flags） | 置 INVALID=0，i6x 不走枚举位 |
| — | `mouse_x/y/z`/`dial`/`keyboard` | 置 0，预留 |

接收端应用映射（robot_adapter，两个来源共用同一函数）：
`switch_raw[0]`→左拨杆（使能门控）、`switch_raw[1]`→右拨杆（夹爪）、
`switch_raw[2]/[3]` 备用；`robot_adapter_map_switch()`: +1→UP，-1→DOWN，0→MIDDLE。

接收端日志（100ms 一条）：
`[remote] online=%u seq=%u ch=%d/%d/%d/%d swA=%d swB=%d swC=%d swD=%d`
（swA~swD 为原始档位 +1=上 0=中 -1=下；SWA/SWB/SWD 两档不会出现 0）。

## 注意事项

1. 两板的 `module_board_comm` 组件**使用同一份源码**（含第 4 分片扩展），勿各自魔改。
2. 发送基址与接收基址**不能相同**（组件 init 会校验）；基址需满足
   基址 + 7 ≤ 0x7FF（每段 8 个消息类型）。
3. 四帧必须使用同一序列号成组发送（组件内部已保证）；收齐 mask=0b1111 才提交，
   丢帧则该组数据不更新，依赖 100ms 超时判离线。
4. 后续如需回传机械臂状态，用本板 0x720 基址的
   `module_board_comm_send_gimbal/chassis/shooter()` 系列即可，协议同源。
