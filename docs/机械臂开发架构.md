## 二、总体架构（照搬底盘模式）

底盘工程验证过的四层结构，机械臂工程 1:1 映射：

```
FreeRTOS 任务层  USERS/Application/Task
  Arm_Task (1kHz)  ──dt──> robot_task_control(dt)
  Can_Task (轮询)  ──────> robot_task_can_receive()
        │
Robot 装配层    ROBOT/（根目录）          ← 对应底盘 ROBOT/ 四件套
  robot_config  整车对象总表 + robot_init() 装配 + robot_enter_safe_state()
  robot_port    HAL FDCAN → bsp_can_driver_ops_t（= fdcan_ops 桥接）
  robot_adapter Ix6 遥控输入 → 各轴命令（扣死区/方向/映射）
  robot_task    周期调度入口：安全门控 → App update → bus_update
        │
App 层         USERS/Application/app     ← 对应底盘 app_chassis/app_lift/app_safety
  app_gantry    龙门 X/Y 线性轴（mm 单位）
  app_arm       2 关节平面臂（rad）
  app_gripper   夹爪（DM 电机）
  app_safety    安全门控（从底盘拷贝，ECF 无此 App）
        │
ECF 组件层     USERS/Components（只读） + USERS/BSP/bsp_*（只读）
  Module: module_motor → module_dm_motor(+bus)   Bsp: bsp_can + bsp_can_dispatcher
  Algorithm: alg_trajectory（每轴一实例） alg_pid alg_math
        │
COD BSP 层     USERS/BSP/cod_hal（HAL 实现）
  hal_fdcan（ISR 回调→fdcan_ops_on_rx）  bsp_uart（SBUS）  bsp_mcu（聚合初始化）
```

## 四、核心数据流

**接收链（反馈帧）**：
```
DM 电机反馈帧 → FDCAN1 RX FIFO0
→ HAL_FDCAN_RxFifo0Callback (hal_fdcan.c)
→ fdcan_ops_on_rx() → bsp_can_notify(RECEIVE_PENDING)
→ dispatcher 置 receive_pending
→ Can_Task: bsp_can_dispatcher_process()
→ 路由表匹配反馈 ID → module_dm_motor_bus_handle_feedback() → module_motor 状态更新
```

**发送链（控制帧）**：
```
Arm_Task 1kHz: robot_adapter_update()（SBUS→命令）
→ 安全门控 module_motor_set_output_allowed(robot.remote.online)
→ app_xxx_update(dt)：alg_trajectory 平滑 → module_motor_set_target
→ module_dm_motor_bus_update(bus, dt)：每周期轮询发送 ≤ budget 帧（MIT 模式）
→ fdcan_ops transmit → FDCAN1 TX FIFO
```

板间通信走 FDCAN2 独立 dispatcher 实例 + `module_board_comm`，协议待定。

## 五、龙门架关键设计点（与机械臂的差异）

1. **单位换算**：线性轴用 mm，配置传动参数宏（皮带齿距×同步轮齿数 / 丝杆导程）：
   `position_mm = position_rad / (2π) × 导程`（或 `× 皮带周长 / 减速比`）。
2. **零点方案**：上电首帧反馈位置 = 机械零点（参考底盘 `s_lift_dm_zero_rad` 首帧锁存写法），绝对坐标在此之上累加换算，**不依赖电机累计角度**——目标位置每次都从零点参考系换算，电机反馈只做增量补偿。
3. **行程限幅**：配置宏 `GANTRY_X_RANGE_MIN/MAX_MM`，目标先限幅再进轨迹平滑，防止撞机械硬限位。
4. **轨迹平滑**：每轴一个 `alg_trajectory` 实例（梯形/S 曲线），App 内下发目标 → 轨迹插补 → 电机目标。
5. **下电回零**：检测到遥控离线沿或 SW 下拨 → 先按轨迹回 0 → 再 disable（复用底盘"离线沿只执行一次"的防轰炸模式）。
6. **使能解锁**：DM 电机需先收到一帧反馈才能使能 → 照搬 `robot_try_enable_motors()`（含参数读取探测帧解锁死锁的写法）。

## 七、与底盘工程的差异速查

| 底盘 | 机械臂 | 说明 |
|---|---|---|
| 4×M3508 + 3×DM | 5×DM（全 MIT） | 无 dji_bus，只有 dm_bus，预算 5 帧/周期 |
| 舵轮/麦轮运动学 alg_mecanum | 龙门线性轴 + 平面臂 | 新写 app_gantry/app_arm |
| 相对角度抬升 | mm 线性轴 + 上电零点 | 换算层在 app_gantry |
| cod-fdcan RxPending | hal_fdcan ISR → fdcan_ops_on_rx | 桥接命名不同，机制相同 |
| USERS/ROBOT | ROBOT/（根目录） | 位置随新目录约定，内容模式相同 |
